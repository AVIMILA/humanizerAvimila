\# ✨ humanizerAvimila



Extension Word qui humanise vos textes localement avec l'IA. \*\*100% privé, gratuit et sans cloud.\*\*



!\[Version](https://img.shields.io/badge/version-1.0.0-blue)

!\[License](https://img.shields.io/badge/license-MIT-green)



\## 🌟 Fonctionnalités



\- ✅ \*\*100% Local\*\* : Vos données restent sur votre ordinateur

\- ✅ \*\*Gratuit\*\* : Pas d'abonnement, pas d'API payante

\- ✅ \*\*Confidentialité totale\*\* : Rien n'est envoyé sur Internet

\- ✅ \*\*Rapide\*\* : Génération en 2-5 secondes

\- ✅ \*\*Personnalisable\*\* : Modifiez le prompt selon vos besoins

\- ✅ \*\*Open Source\*\* : Code entièrement disponible



\## 📋 Prérequis



\- Windows 10/11

\- \*\*LM Studio\*\* : https://lmstudio.ai/

\- \*\*Python 3.8+\*\* : https://www.python.org/

\- \*\*Node.js 16+\*\* : https://nodejs.org/

\- \*\*Microsoft Word\*\* (2016 ou supérieur / Microsoft 365)

\- \*\*Carte graphique\*\* : NVIDIA avec 6 Go VRAM minimum (RTX 2060 testée)



\## 🚀 Installation



\### 1. Installer LM Studio et le modèle



1\. Téléchargez \[LM Studio](https://lmstudio.ai/)

2\. Installez le modèle \*\*Mistral 7B Instruct v0.3 (Q4\_K\_M)\*\* (\~4.37 GB)

3\. Démarrez le \*\*Local Server\*\* sur le port \*\*1234\*\*
